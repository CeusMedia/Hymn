### Further options

These options are not listed by `hymn help`:

| Option | Meaning |
|--------|---------|
| <code>-vv &#124; --very-verbose</code> | Show even more details, eg. memory usage – includes `--verbose` |
| `--interactive=[yes,no]` | Ask for missing values (default: yes) – with `no`, missing values are errors |
| <code>-h &#124; --help</code> | Show help screen, like `hymn help` – only without command |
| `--version` | Show version, like `hymn version` |

The flag `-r` / `--recursive` is an option of [`test-syntax`](test-syntax.md) only.
